# petaricon の「付き方」 実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 子ごと・軸ごとの付き方(左/右/左右/中央、上/下/上下/中央)を、決まった形の Slint の式として書き、読み、ドラッグで保ち、自由配置の整えから推定できるようにする。

**Architecture:** 付き方の式の書き出しと見分けは純粋な関数として新しいモジュール(`crates/slint-doc/src/anchor.rs` か `crates/app/src/anchor.rs`。テストしやすい方)に置く。session は位置・大きさの書き換え(ドラッグ・大きさ変更・数の入力)をこのモジュール経由にし、推定は `tidy::free` の結果と入れ物の大きさから計算する。

**Tech Stack:** Rust、Slint =1.18.1

**Spec:** `docs/superpowers/specs/2026-10-24-anchors-design.md`

## Global Constraints

- 設計書 1 章のとおり。特に「.slint だけが正」「付き方が左・上のままの要素は 1 バイトも変わらない」。
- 書き込む前に確かめる(2d2186a の検査)。
- 画面の文言は日本語、タップの的は 44px 以上。Slint は `=1.18.1`。
- コミットの形は SDD の common.md のとおり。

## Review Focus

1. 付き方の切り替えで、見た目の位置と大きさが変わらない(プレビューの位置で確かめる)。
2. ドラッグ・大きさ変更・数の入力で、付き方が保たれる。
3. 決まった形でない式を、黙って px で上書きしない。
