# 自由配置の Tidy(整える)設計書

- 日付: 2026-10-21
- 状態: 承認済み
- 関連: `2026-10-20-slint-touch-editor-design.md`(本体の設計書)

## 1. 目的

旧 Tidy(縦一列・横一列のレイアウトへの変換)は Stack に改名した。新しい Tidy は、自由配置のまま子要素の位置と寸法を「意図していそうなきれいな値」に寄せる。L 字は L 字のまま、ずれだけを直す。

## 2. 範囲

- 対象: 選択中のコンテナの直下の子だけ(Stack と同じ)。孫以下は触らない。
- 書き換えるのは子の `x` / `y`、および明示的に書かれている `width` / `height` だけ。
- 断る場合: 選択がレイアウト要素(Stack 済み)、子に `for` / `if` がある、子が 0、プレビューが古い(コンパイルエラー中)。
- 1 回の Tidy は 1 回の Undo で戻る。
- 許容値 T は設定で 4〜48px、初期値 16px。

## 3. アルゴリズム(`tidy` クレート、Slint 非依存)

入力: 子の矩形(親基準の x, y, w, h)、各子の幅・高さが明示されているか、コンテナの幅・高さ、許容値 T。
出力: 新しい矩形と、適用した関係の一覧。

### 3.1 寸法をそろえる(先に確定する)

軸ごと(幅、高さ)に、明示されている寸法を並べ、隣との差が T 以内かつ範囲が T 以内のまとまり(2 個以上)を、中央値(整数に丸め)にそろえる。

### 3.2 位置の関係(x と y は独立に、同じ手順で求める)

変数は各子の始点座標 p_i。基準は 始点 p、中心 p + s/2、終点 p + s。

1. **そろえ**: 基準ごとに座標のまとまり(範囲が T 以内、2 個以上)を作る。各要素は 1 軸につき 1 つのまとまりにだけ属する。候補が複数あれば、要素数が多いもの、同数なら範囲が狭いものを選ぶ。式: 同じまとまりの基準座標が等しい。ただし、その軸で連鎖(項目 3)の歩幅の平均が T/2 を超えるとき、同じ連鎖の要素を 2 個以上含むまとまりは作らない(連鎖の最初の 1 個だけ残す)。T/2 以下なら、その軸にそろった連鎖として通常どおりそろえ、歩幅は 0 として解く。
2. **等間隔**: もう一方の軸で同じそろえのまとまりに属する要素(同じ行・列)が 3 個以上あれば、座標順に並べたすき間の最大と最小の差が T 以内のとき、すき間をすべて等しくする。
3. **同じずれの繰り返し**: 全ての組 (i, j) の始点のずれベクトル (Δx, Δy) を作る(長さが T 未満の組は除く)。
   - **連鎖**(先に探す): 3 個以上の要素が並び、隣どうしのずれ(歩幅、長さ T 以上)がすべて両成分とも 1.5T 以内で近いもの。要素は歩幅の平均への射影順に並べる(入力順に依存しない)。式: 隣どうしの差が、軸ごとに共通の歩幅変数に等しい。連鎖の中では組が要素を共有してよい。連鎖の要素どうしのずれは連鎖が含むので、別の繰り返しとしては報告しない。丸めは歩幅を整数にしてから行う。
   - **組のまとまり**: 連鎖に含まれない組について、両成分とも T 以内で近いベクトルのまとまりが 2 組以上あれば、それらのずれを等しくする(軸ごとに p_j − p_i = p_l − p_k)。
4. **対称**: 軸の候補は、コンテナの中心線と、子全体の外接矩形の中心線。各候補について次を数え、関係の多い候補を採用する(同数ならコンテナの中心線)。
   - 組: 中心の和が 2c から T 以内、寸法の差が T 以内、もう一方の軸の中心の差が T 以内。式: center_i + center_j = 2c。
   - 単独: 組に入らない要素の中心が c から T 以内。式: center_i = c。

### 3.3 まとめて解く

軸ごとに、見つけた式をすべて満たすことと、元の位置から動かさないことを、重み付きの最小二乗で同時に満たす。

    最小化  Σ_k 1000 · (a_k · p − b_k)²  +  Σ_i (p_i − p0_i)²

正規方程式を密行列のガウス消去で解き(子は数十個まで想定)、最後に整数へ丸める。この方式なら、ルールを適用する順番で結果が変わらない。

### 3.3.1 実装で追加した決まり(レビューで承認)

- **食い違いへの対処**: 解いた結果、どれかの要素が元の位置から T より大きく動く場合は、関係の種類を「繰り返し → 対称 → 等間隔」の順に外して解き直し、全要素が T 以内に収まる最初の組み合わせを採用する(そろえだけなら必ず T 以内に収まる)。外した種類は報告しない。
- **外接矩形の中心線による対称**: 子どうしの端の組は自明に対称になるため、この候補は「組が 1 つ以上、関係が 2 つ以上、かつコンテナの中心線より関係が多い」場合だけ採用する。
- **丸め**: 整数へ丸める前に 0.1 単位にそろえ、わずかな残差で同じ値になるべき座標が分かれないようにする。
- **報告と結果の一致**: 丸めた後の矩形で、報告するすべての関係が成り立つことを確かめる。成り立たない関係は報告せず、該当する種類を外して解き直す。
- **決定性**: 入力の順番を入れ替えても、各要素の結果は同じになる。

### 3.4 出力する関係

- 寸法そろえ(軸、要素、値)
- そろえ(軸、基準、要素、座標)
- 等間隔(軸、要素、間隔)
- 繰り返し(ベクトル、組)
- 対称(軸、中心座標、組、単独)

## 4. エディタへの組み込み

- ツールバー 2 段目の先頭に「Tidy」を置く(Tidy, Stack, Unstack, Extract)。
- メニューに「設定」を足し、許容値を − / 値 / +(4px 刻み、4〜48px)で変える(44px 以上)。
- 設定は保存先フォルダの `.settings`(`key=value` の行)に記録する。
- 実行後は、適用した関係をキャンバスに重ねて表示し、次の操作で消す。
  - そろえ: 点線
  - 等間隔: すき間に同じ印
  - 対称: 軸の線
  - 繰り返し: 対応する組をつなぐ点線
- 画面下に「そろえ 3・等間隔 1・対称 1」のように要約を出す。変更がなければ「整える箇所はありませんでした」と出す。
- 選択はコンテナのまま。

## 5. テスト

- `tidy` クレート:
  - L 字が L 字のまま整う
  - ほぼ格子
  - ほぼ対称の組と中央寄せ
  - ほぼ等間隔
  - 関係が食い違う配置で破綻しない
  - そろっていない配置は動かない
  - 明示されていない寸法は変えない
  - 許容値の境界
- エディタ: 1 回の Undo で戻る、断る条件、設定の保存と読み込み、要約の表示。
